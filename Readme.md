**“I was lost, now I found the way.”**

---

## 🚦 Problem Statement
In Kathmandu, millions rely on buses daily, but with no digital maps or real-time information, commuters are often left:
- ❌ Confused about which bus to take  
- ⏳ Delayed due to missed routes  
- 🗣️ Dependent on word-of-mouth guidance  
- 🌍 Tourists and newcomers struggle even more since **no centralized source of information exists** in English or Nepali  

---

## 💡 Solution
**बाटो भेटियो (batoVetiyo)** is a mobile-first web application that serves as a **digital guide for public transport in Kathmandu**.  

It helps users by providing:
- 📍 Nearby bus stops based on current location  
- 🚌 Best bus routes to reach any destination  
- ⏱️ Estimated fares and travel times  
- 🌐 Multi-language support (English & Nepali)  
- 🔔 Travel reminders and suggestions for frequent commuters  

---

## ✨ Key Features
- 🗺️ Interactive city map with bus routes  
- 🛣️ Route planner from current location to destination  
- 📝 List of stops along the journey with walking distances (if any)  
- 📡 Offline mode with cached routes for low-connectivity areas  
- 🎯 Designed for students, daily commuters, and tourists  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS3 (Tailwind), JavaScript, React  
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL / MySQL  
- **APIs:** Google Maps / OpenStreetMap, Geolocation API  
- **Deployment:** Netlify (frontend), Railway (backend)  

---

## 🎬 Expected Output / Demo Flow
1. User opens the app → current location is **automatically refreshed** on the map  
2. User selects/enters a destination  
3. App displays:  
   - Nearest bus stop from user’s location  
   - Recommended public vehicle (bus/micro/tempo)  
   - Bus route number & all stops along the way  
   - Walking distance (if required)  
   - Estimated fare & travel time  

**Example Route:**  
Ratnapark → Singha Durbar West Stop → Kamalpokhari → Gyanehwor → Ratopul →
Gaushala → Mitrapark → Chabahil → Chuchepati → Bouddha → Jorpati →
Gokarneshwor Mahadev Temple → Nayapati → Sundarijal

---
